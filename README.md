# 🏫 نظام الحضور والغياب الذكي - مدرسة قطوف الخير

تطبيق ويب متكامل وسريع مصمم خصيصاً لـ **مدرسة قطوف الخير** لإدارة حضور وغياب الطلاب بدقة وسرعة فائقة بدون تعقيدات الإكسل وتدوير الأسماء.

---

## 🌟 المواصفات المنفذة

### 1. 👩‍🏫 كادر المعلمات (5 معلمات - صف واحد لكل معلمة):
* **أ. ندى** (فصل أ. ندى - دوام: السبت / الإثنين / الأربعاء)
* **أ. نسرين** (فصل أ. نسرين - دوام: الأحد / الثلاثاء / الخميس)
* **أ. مرام** (فصل أ. مرام - دوام: السبت / الإثنين / الأربعاء)
* **أ. أسيل** (فصل أ. أسيل - دوام: الأحد / الثلاثاء / الخميس)
* **أ. فاطمة** (فصل أ. فاطمة - دوام: السبت / الإثنين / الأربعاء)

> 💡 **نظام الدوام المبسط:** كل معلمة مسؤولة عن **صف واحد فقط** يُسجل حضوره في أيامه المقررة كل 3 أيام.

---

### 2. ⚡ ميزة الـ 15 ثانية لتسجيل الحضور:
* **زر "الجميع حاضر (نقرة واحدة)":** يحدد جميع طلاب الفصل حاضرين فوراً بلمسة واحدة، وتكتفي المعلمة بنقر الطالب الغائب فقط.
* **ترتيب الأسماء أبجدياً تلقائياً (أ - ي):** أسماء الطلاب تُرتب أبجدياً تلقائياً لتسهيل المتابعة البصرية.
* **إبلاغ ولي الأمر عبر واتساب:** زر مباشر يفتح محادثة واتساب مع ولي أمر الطالب الغائب بنص اعتذار وتنبيه جاهز.
* **مؤثرات صوتية تفاعلية:** نغمات تفاعلية ناعمة عند نقر الأزرار وحفظ السجل (مع إمكانية كتم الصوت).

---

### 3. ☁️ قاعدة البيانات السحابية (Supabase):
* متصل مباشرة بسحابة **Supabase** المجانية لمزامنة بيانات الحضور بين هواتف كافة المعلمات ولوحة المدير لحظياً ومن أي مكان.
* يدعم العمل دون اتصال (Offline) مع حفظ محلي تلقائي في حال انقطاع الشبكة.

---

### 4. 📊 لوحة تحكم المدير والإدارة:
* **عداد بياني دائري (Circular Gauge):** يوضح نسبة الحضور العامة وتقييم الالتزام المدرسي.
* **شريط التوزيع البصري الملون:** يوضح نسب الحاضرين والغائبين والمتأخرين.
* **جدول متابعة المعلمات:** يوضح حالة كل معلمة وتوقيت رصدها للفصل.
* **كشف الغياب العام وتصدير Excel:** تحميل تقرير إكسل رسمي منسق لليوم بنقرة واحدة.

---

### 5. 📁 رفع ملفات الإكسل والفرز الأبجدي:
* ترفع المعلمة ملف إكسل فصلها (.xlsx / .xls / .csv).
* يكتشف النظام الأعمدة تلقائياً (اسم الطالب، رقم القيد، هاتف ولي الأمر).
* **يفرز الأسماء أبجدياً أوتوماتيكياً (أ - ي)** قبل الحفظ.

---

## 🚀 طريقة التشغيل

1. **محلياً على الكمبيوتر:**
   * اضغط نقراً مزدوجاً على ملف: `تشغيل_النظام.bat`.
2. **عبر هواتف المعلمات:**
   * اضغط زر **"فتح من الجوال"** في شريط التطبيق العلوي لمعرفة الرابط المحلي على شبكة المدرسة، أو افتح رابط الاستضافة السحابية.
